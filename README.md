# WTBI — Will They Buy It

A Claude skill for deep conversion reviews of websites, landing pages, stores, listings, and products. It walks realistic buyer personas through the page, audits it against proven conversion lenses, maps buyer objections, and returns a verdict plus prioritized changes.

## Install

Copy this folder into `~/.claude/skills/wtbi/` (Claude Code), or zip it and upload it as a skill in Claude.ai.

See [SKILL.md](SKILL.md) for the full skill.
